# Capstone Project — Sales & Order Analytics Dashboard



## Project Overview

This capstone project focuses on analyzing sales, orders, products, customers, and store performance using data analytics and interactive Power BI visualizations. The dashboard presents key performance indicators (KPIs) and business insights to help understand sales trends and overall business performance.

## Tools & Technologies

* **SQL** — Data querying and database operations
* **Python** — Data analysis
* **Pandas** — Data cleaning and transformation
* **Power BI** — Interactive dashboards and data visualization
* **Microsoft Power Query** — Data preparation and transformation


## Dataset Details

The project data model includes the following tables:

* **Brands** — Brand information
* **Categories** — Product category details
* **Customers** — Customer information
* **Orders** — Order records
* **Order Items** — Individual items associated with orders
* **Products** — Product information
* **Staffs** — Staff details
* **Stocks** — Inventory and stock information
* **Stores** — Store details
* **Customer Segments** — Customer segmentation data

## Conclusion

This capstone project demonstrates practical skills in data preparation, data analysis, data modeling, and business intelligence. The interactive Power BI dashboard helps present business performance and key trends in a clear and structured manner.
